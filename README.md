# 🍌 بانانا کوییز (کوییز موز)

بازی کوییز آنلاین فارسی — ساختهٔ **محمد مهدی عدالتیان**

## این ریپو چیه؟

همهٔ فایل‌های سایت «بانانا کوییز» همین‌جاست. با فعال‌کردن **GitHub Pages** روی این ریپو، بازی با یک لینک آنلاین برای همه اجرا می‌شود.

## فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | صفحهٔ اصلی بازی (از همین شروع کن) |
| `style.css` | ظاهر و انیمیشن‌ها |
| `app.js` | موتور بازی: کوییز، پارتی، تایپ‌بتل، ایکس‌پی |
| `voice.js` | 🎙️ ویس کال WebRTC (۲ تا ۴ نفر) + مینی‌گیم‌ها |
| `minigames.js` | 🎲 منچ و مار و پله داخل ویس کال |
| `questions.js` | ۸۴۰ سؤال در ۷ دسته (هر دسته ۱۲۰ سؤال) |
| `battle-texts.js` | متن‌های مسابقهٔ تایپ‌بتل |
| `avatar.js` | آواتار تمام‌قد با ۳ زاویه + فروشگاه لباس |
| `robots.txt` | تنظیمات موتورهای جستجو |
| `کوییز-موز.html` | نسخهٔ آفلاین تک‌فایلی (بدون اینترنت هم اجرا می‌شود) |

## امکانات بازی

- 📝 **کوییز**: ۷ دسته — فوتبال، والیبال، بسکتبال، گیم، اطلاعات عمومی، انگلیسی، ریاضی
- 🎉 **پارتی**: روم تا ۱۰ نفر با کد، حالت کوییز یا تایپ‌بتل، انتخاب راند ۱ تا ۵
- 🎙️ **ویس کال**: تماس صوتی ۲ تا ۴ نفره بدون هیچ اپ اضافه (WebRTC) با دکمهٔ گندهٔ میکروفون و انتخاب اسپیکر/هندزفری — موزیک بازی هنگام تماس قطع و بعد از تماس خودکار برگردانده می‌شود
- 🎲 **مینی‌گیم داخل ویس**: منچ و مار و پله با آماده‌باش و شروع توسط سازنده + صدای تاس، بالا رفتن از پله، نیش مار و فانفار برد (برای همهٔ بازیکن‌ها همگام)
- ⌨️ **تایپ‌بتل**: متن ۲۱+ خطی، ۳ جون، هر کلمهٔ غلط ۱ جون کم می‌کند، راند ۲۰ ثانیه
- 👤 **آواتار**: شخصیت تمام‌قد قابل چرخش + لباس، شلوار، کفش، عینک، کلاه
- ⭐ **ایکس‌پی**: با بازی جمع کن، باهاش لباس‌های قشنگ بخر!
- 📸 **شیر نتیجه** به‌صورت عکس
- 🏆 رنک‌های ۵ سطحی موزی + موزیک و افکت صوتی

## راه‌اندازی سایت

۱. روی ریپو برو: **Settings → Pages**
۲. قسمت **Branch**: گزینهٔ `main` و پوشهٔ `/ (root)` را انتخاب کن
۳. **Save** بزن — بعد از ۱-۲ دقیقه لینک سایت بالا می‌آید:

```
https://نام-کاربری.github.io/نام-ریپو/
```
